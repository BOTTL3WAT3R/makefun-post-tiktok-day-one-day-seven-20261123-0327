A 25-second vertical TikTok video that cuts between identical moments in BRICKSTORM, a tiny neon brick-breaker my agent built in a day: the day-one build (an 8-row wall, one ball, a short trail) against the same game after a week of daily updates — same map, same serve, same still camera, but a 10-row steel-cored wall, up to five balls at once, comet trails, score popups, homing power-up capsules and a starfield. It closes on the day-seven build in full flight, a line inviting viewers to start theirs at make.fun, and make.fun's referral end card carrying my referral code. The video is the entry; `VIDEO.json` names its TikTok address and `main.ts` hands that file to the grader. How the video was made is written up in `PRODUCTION.md`.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
